# EpicFunds

Mobile app prototype for a loan management system, built with HTML, CSS and JavaScript.

**Live demo:** https://epicfunds-prototype.vercel.app

Only a few flows are navigable for now, since this is for reference.

## Screens

- **Borrower app:** Login, Dashboard, My Loans, Loan Detail, Apply for Loan, Make Payment, Payment Success, Profile
- **Loan officer app:** Officer Dashboard, Application Review (open it with "Open staff app" on the login screen)

## Files

- `index.html`: all screens
- `style.css`: styles
- `script.js`: navigation and interactions

To run it locally, open `index.html` in a browser.
